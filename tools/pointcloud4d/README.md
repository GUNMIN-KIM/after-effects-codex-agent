# pointcloud4d — RGB + Depth + Alpha → 4D 포인트클라우드 영상

원본 영상, Depth 패스, Alpha(매트) 패스를 받아 매 프레임을 3D 포인트클라우드로 재구성하고, 가상 카메라가 그 안을 비행하는 시네마틱 영상을 만든다. AE 없이 Python만으로 동작하며, 결과물은 AE에 푸티지로 가져와 추가 합성할 수 있다.

## 입력 규칙

| 입력 | 조건 |
|---|---|
| `--rgb` | 원본 영상. 오디오가 있으면 결과물에 그대로 붙는다 |
| `--depth` | 원본과 같은 해상도·프레임레이트. **어두움 = 가까움, 밝음 = 멂** (Depth-Anything 반전형) |
| `--alpha` | 흰색 = 피사체. 피사체와 환경의 셰이딩을 분리하는 데 쓴다 |

## 실행

```bash
pip install numpy opencv-python-headless imageio-ffmpeg   # ffmpeg가 PATH에 있어야 함
python render_pointcloud4d.py --rgb in.mp4 --depth Depth.mp4 --alpha Alpha.mp4 --out out.mp4
# 미리보기 스틸만: --frames 30,250,430  (out_0030.jpg ... 로 저장)
```

첫 실행 시 `<out>_analysis.npz`를 만든다. 여기에는 Depth 프레임 차이로 찾은 전환 구간, 피사체 평균 깊이·세로 중심, 오디오 RMS가 들어간다. 이후 렌더는 워커 수만큼 프레임을 나눠 병렬 처리한 뒤 H.264(CRF 16)와 AAC로 합친다.

## 파이프라인

1. **재구성**: 안정 지터 샘플링(환경 2px, 피사체 1px)으로 Depth를 역투영한다(`Z = 2.5 + 10.5·d^1.8`). 8-bit 계단은 디더링하고, 깊이 불연속에 생기는 flying pixel은 제거한다.
2. **4D 모션**: 인트로에서 입자가 모여 형상을 만들고, 전환 구간에는 피사체 축을 중심으로 소용돌이 폭발 후 재조립한다. 피사체 실루엣에서는 불씨가 떠오르고, 아웃트로에서는 소용돌이치며 흩어진다.
3. **셰이딩**: 피사체는 원색을 따뜻하게 강조하고 좌측 시안·우측 오렌지 림라이트를 준다. 환경은 틸 톤으로 탈채도한다. 깊이를 따라 이동하는 LiDAR 스캔 펄스와 대기 안개를 더한다.
4. **카메라**: Catmull-Rom 키프레임 궤도(±18°, 로우앵글, 돌리줌 포함)에 핸드헬드 흔들림을 더한다. 피벗은 피사체 깊이를 따라가며, 궤도 거리도 그 깊이에 비례한다.
5. **포스트(언리얼 룩)**: Z-버퍼 포인트 스플랫 + 가산 헤이즈, 볼류메트릭 백라이트, 갓레이, 블룸 피라미드, 아나몰픽 스트릭, ACES 톤맵, 색수차, 비네트, 그레인, 2.39:1 레터박스. 블룸과 림은 오디오 RMS에 반응한다.

## 튜닝 포인트

- `CAM_KEYS`: 카메라 궤도 (시간, yaw, pitch, 거리, fov, roll). 단일 시점 Depth이므로 yaw ±20°를 넘기면 깊이 레이어가 줄무늬로 벌어진다.
- `Z_NEAR/Z_FAR`, 지수 `1.8`: 원근감 강도.
- `render_frame` 안의 `period`(스캔 주기), 불씨 비율(`ember`), 버스트 강도(`burst`, `ang`).
