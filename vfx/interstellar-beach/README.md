# Interstellar Beach — 10초 VFX 파이프라인

4초짜리 세로 실사 클립(해변·인물·강아지)을 10초 VFX 샷으로 확장하는 스크립트 모음이다. 원본 영상과 렌더 결과물은 저장소에 넣지 않는다.

## 샷 구성 (30fps, 300프레임, 1080×1920)

| 시간 | 내용 |
|---|---|
| 0.0–2.0초 | 원본 실시간. 해변 위로 모래가 흐르기 시작하고, 수평선에서 먼지 장벽이 솟아오름 |
| 2.0–6.0초 | 0.52배 슬로모션(광류 보간). 먼지 장벽이 바다를 삼키고 인물을 지나 카메라까지 덮침. 먼지 속에서 하늘이 우주로 바뀌고 블랙홀이 드러남. 쌍둥이 비행선이 머리 위를 통과(소닉붐) |
| 5.6–6.6초 | 바다가 밀려와 해변이 잠김(서지 파도, 거품 전선) |
| 6.6–8.8초 | 수위 상승 → 강아지와 인물이 물에 잠기고 가라앉아 사라짐(물보라, 기포) |
| 8.8–10초 | 블랙홀 빛이 반짝이는 밤바다, 천천히 푸시인 |

## 단계와 스크립트

| 단계 | 스크립트 | 비고 |
|---|---|---|
| 1. 플레이트 추출 | `ffmpeg -i source.mov plate/p_%04d.png` | 회전 메타데이터를 반영해 1080×1920으로 추출 |
| 2. 2D 매치무브·수평선 | `track.py` | 모래·하늘 특징점 LK 추적 → 프레임별 유사변환, 하늘/바다 경계로 수평선 측정 |
| 3. 첫 프레임 마스크 | `sam_mask.py` | SAM 2.1-L(Ultralytics), 인물·강아지·가방 박스 프롬프트 |
| 4. 매트 | `run_matte.py` | **MatAnyone2**로 122프레임 알파 추출(CPU 약 6초/프레임) |
| 5. 블랙홀 | `blackhole.py` → `bh_shade.py` | 슈바르츠실트 측지선 적분(RK4)으로 픽셀별 강착원반 충돌·탈출 방향을 한 번 계산하고, 프레임마다 원반 회전·도플러·중력 적색편이·렌즈된 별을 셰이딩 |
| 6. 비행선 | `ships_flyby.py` → `exr2npy.py` | Blender Cycles, 플레이트 카메라(26mm 환산, 롤 −1.5°) 매칭, 모션블러, 엔진 화면좌표 기록 |
| 7. 합성 | `comp.py <시작> <끝>` | 그레이딩 플레이트 → 우주 하늘 → 먼지 장벽 → 레이트레이싱 수면(게르스트너 + 잔물결, 프레넬, 거품) → 비행선·트레일 → 리라이트된 인물/강아지(수면 컷, 가라앉음, 바운스광) → 물보라·기포 → 모래 입자·먼지 베일 → 블룸·아나모픽 스트릭·색수차·그레인 |
| 8. 사운드 | `audio.py` | 원본 0–2초 + 바람·모래·럼블, 오르간 드론, 도플러 휘시·소닉붐, 파도·물보라·기포 |

`test_frames.py 140,205,250` 은 지정 프레임만 렌더해 확인용 스트립을 만든다.

## 리라이트

인물과 강아지는 낮 햇빛으로 찍혔기 때문에 단계별로 조명을 바꾼다.

- 먼지 폭풍: 하이라이트 압축과 채도 감소로 햇빛 느낌을 없애고, 따뜻하고 탁한 톤과 뒤에서 오는 먼지 산란광을 넣는다.
- 블랙홀 밤: 차가운 하늘 필을 깔고, 블랙홀 화면 위치에서 오는 금색 역광 림을 준다. 림 방향은 매트의 가장자리 법선과 광원 방향의 내적으로 정한다. 흰 털·머리카락·셔츠처럼 밝은 가장자리는 더 많이 빛난다.
- 수면 근처: 반짝이는 물에서 올라오는 바운스광을 더한다.

## 필요 환경

- Python 3.11(매트), Python 3.13 + `bpy`(Blender 5.x 모듈, 블랙홀·비행선·합성)
- `numpy`, `opencv-python-headless`, `scipy`, `torch`, `ultralytics`, MatAnyone2 저장소(`../ext/MatAnyone2`)와 `matanyone2.pth`
- 비행선 에셋: `games/gemini-neon/blender/ship.py`로 만든 `ship.glb`
